# 午间食单 · GitHub Pages 部署

1. 解压 ZIP。进入 GitHub 仓库，在 Code 页面选 Add file → Upload files。
2. 上传解压后的全部文件，确保 index.html 和六张 WebP 图片直接位于仓库根目录。提交到 main 分支。
3. 在 Settings → Pages 里，把 Source 设为 Deploy from a branch，选择 main 和 / (root)，然后点 Save。
4. 部署完成后，Settings → Pages 会显示访问地址。打开该地址检查首页、菜品图片与口味下拉框。

页面由静态 HTML、CSS、JavaScript 和本地图片组成，无需安装依赖或设置 API 密钥。
午餐记录和偏好保存在当前浏览器与网站地址下。首次打开新的 GitHub Pages 地址时会从默认设置开始。
